# Annoying PPTs

Two standalone skill packages distilled from university presentation examples:

| Package | Use |
| --- | --- |
| [annoying-ppts](annoying-ppts/SKILL.md) | OpenAI/Codex environments with presentation and file tools |
| [annoying-ppts-universal](annoying-ppts-universal/SKILL.md) | Agent Skills compatible AI platforms without OpenAI-specific instructions |

For Codex, copy the entire `annoying-ppts` folder into the local skills directory. The skill is discoverable on the next turn. Import the entire `annoying-ppts-universal` folder on other Agent Skills compatible platforms.

For platforms that accept only one knowledge document, use [SINGLE-FILE.md](annoying-ppts-universal/SINGLE-FILE.md). If the custom instruction field is short, paste [CORE-PROMPT.md](annoying-ppts-universal/CORE-PROMPT.md) and attach the single-file document as knowledge when supported.

The packages include visual recipes, use-case routing, page patterns, corpus notes, and quality checks. Source PPT/PDF/image examples are not redistributed and are not required at runtime. The skills treat those examples as design research, not factual evidence or reusable third-party assets.
